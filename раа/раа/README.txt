ЗОЛОТОЙ ТЕНГЕ — версия для Telegram (Mini App)
==============================================

В АРХИВЕ
  index.html — вся игра. Telegram SDK уже подключён.

КАК ЭТО РАБОТАЕТ
  Mini App — это обычный сайт, который Telegram открывает внутри себя по кнопке бота.
  Telegram даёт игре: имя игрока, облачное сохранение в аккаунте Telegram,
  вибрацию (отдачу) при кликах и системную кнопку «Назад».

ШАГ 1. Выложи index.html на хостинг с HTTPS (любой из вариантов, все бесплатные)
  • Netlify Drop — https://app.netlify.com/drop — перетащи папку с index.html, получишь ссылку.
  • GitHub Pages — создай репозиторий, загрузи index.html, включи Pages в настройках.
  • Vercel — https://vercel.com — новый проект, загрузи файл.
  Результат — адрес вида https://что-то.netlify.app

ШАГ 2. Создай бота
  В Telegram открой @BotFather → /newbot → придумай имя и username (должен кончаться на bot).
  BotFather пришлёт токен — никому его не показывай, для игры он сейчас не нужен.

ШАГ 3. Подключи игру к боту (любой способ)
  А) Отдельное приложение:  @BotFather → /newapp → выбери бота → название, описание,
     картинка 640×360 → вставь ссылку из шага 1 → придумай короткое имя (например game).
     Ссылка на игру: https://t.me/ИМЯ_БОТА/game
  Б) Кнопка в чате бота:  @BotFather → /mybots → бот → Bot Settings → Menu Button →
     вставь ссылку из шага 1 и текст кнопки «Играть».

ШАГ 4. Открой игру в Telegram и проверь
  Клики дают лёгкую вибрацию, кнопка «Назад» вверху закрывает магазин/настройки/планету,
  прогресс сохраняется в облаке Telegram и откроется на телефоне и компьютере.

ЧТО ПОМЕНЯТЬ ПЕРЕД ЗАПУСКОМ МОНЕТЫ $TENGE
  Открой index.html в любом редакторе, найди TOKEN_CONFIG и впиши адрес контракта
  и ссылки (купить, Telegram-канал, X, график). Потом загрузи файл на хостинг заново.

ЧЕГО НЕТ В ЭТОЙ ВЕРСИИ (нужен свой сервер)
  − общий рейтинг всех игроков (пока виден только свой результат);
  − торговая площадка, подарки, объявления, админ-панель;
  − вывод реальных денег.
  Всё это работало на базе данных Claude. Для Telegram это делается через свой сервер
  (например, Supabase) — можно подключить следующим шагом.
